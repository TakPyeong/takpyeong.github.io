建议尺寸
--------
封面 cover.jpg：横版，约 2000 x 1250 px（首页第一张建议 2560 x 1440 px）
详情大图 01.jpg：横版 16:9，约 2400 x 1350 px
作品图 02~04.jpg：横版 3:2，约 1800 x 1200 px
profile.jpg：正方形，600 x 600 px

像素长边不超过 2560 px、单张控制在 1 MB 以内，网页打开会更流畅。
用 jpg 或 webp 都可以，如果你用 webp，记得把 index.html 里对应的 .jpg 改成 .webp。

简历
----
把简历 PDF 命名为 resume.pdf，放在 index.html 同一个文件夹（网站根目录）。
